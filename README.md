# SPp — школьный портал (PHP + MySQL + Bootstrap)

Готовый стартовый проект школьного сайта с ролями (ученик/учитель/админ), заданиями, объявлениями, журналом оценок, поддержкой и профилем.

## Запуск
1. Импортируйте БД:
   ```bash
   mysql -u root -p < sql/spp_schema_and_seed.sql
   ```
2. Настройте доступ к БД в `config.php`.
3. Запустите сервер:
   ```bash
   php -S 127.0.0.1:8000
   ```
4. Откройте `http://127.0.0.1:8000`.

## Страницы
- `index.php` — главная, посты, лайки, комментарии, открытие изображения.
- `register.php` — регистрация от 8 лет, +7 телефон, пароль от 8 символов, выбор класса, captcha.
- `login.php` — вход по телефону/username + пароль + captcha.
- `announcements.php` — объявления, комментарии и оценка.
- `assignments.php` — задания, тесты, фильтрация по предмету/классу, сроки сдачи.
- `journal.php` — онлайн журнал, сортировка учеников по алфавиту, фильтры.
- `support.php` — запросы в поддержку (до 1500 символов, captcha, дата).
- `profile.php` — редактирование данных, аватар, «о себе».
- `admin.php` — управление учениками, выставление оценок, ответы поддержки.
